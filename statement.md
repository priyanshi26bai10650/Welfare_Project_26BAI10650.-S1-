 1. Problem Statement
    The Inclusion Welfare System is a system based on Python which aids in the management of basic citizen information and the checking of eligibility for welfare schemes.
    With a manual system, it can take a long time to check the various eligibility conditions for citizens and errors may occur. This project offers a simple method for entering citizens' details and automatically determines which welfare schemes match the information provided.

2. Scope of the project
   The project includes:
    - Registering citizen information
    - Validating age and income
    - Checking disability information
    - Checking welfare scheme eligibility
    - Assigning multiple schemes (if applicable)
    - Saving citizen records in a JSON file
    - Viewing registered citizens
    - Generating a welfare analytics report
    - Testing the welfare eligibility rules
   The online government services, payment processing, user authentication, the web interface and the cloud database are all not part of the present project.

3. Target Users
   The system can be used as a basic welfare management and eligibility-checking system by: 
    Welfare administrators, Community service workers ,Organizations managing welfare records, Students and developers learning about rule-based systems.

 4. High-Level Features
    The main features of the system are:
    - Citizen registration
    - Input validation
    - Welfare eligibility checking
    - Assigning several welfare schemes
    - JSON data storage
    - Viewing citizen records
    - Welfare analytics report
    - Automated testing
